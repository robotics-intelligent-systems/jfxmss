# AI-Powered Marine Systems Simulation Platform

The VesselAI project enables maritime digitization. OSAB is a project that develops open-source, solar-powered, autonomous, boats. BlueOS is a modular, robust, and efficient platform for managing a vehicle or robot from its onboard computer. Digital twin of Gunnerus vessel. UNav-Sim is an open-source cutting-edge underwater robotics simulator tool. LOTUSim is a real-time maritime simulation platform. Integrating a high fidelity ship maneuvering simulator with ROS2. SIMDIS Software Development Kit (SDK). WaveBEM Nonlinear Unsteady Potential Flow Solver. The Mobile Ship Bridge is a configurable ship’s bridge system. SIREHNA's Scientific Computing Toolbox. The Marine Systems Simulator (MSS) is a Matlab and Simulink library. A FreeCAD workbench aiding in naval vessel design. Development of an open-source implementation of the OpenBridge Design System. Modelica library for naval architecture simulations. FastSim is a Rust reimplementation of PathSim. Framework for simulating and evaluating autonomous ship collision avoidance (COLAV) control strategies. OSP libcosim is a C/C++ library for co-simulation. xdyn is a lightweight ship simulator. DCPLib is a C++ implementation of the Distributed Co-Simulation Protocol (DCP). Combining Vessel.js with OpenBridge (AHO). Imaging sonar simulation for real-time underwater applications. OceanSim is a GPU-Accelerated Underwater Robot Perception Simulation Framework. A glider flight model for Slocum ocean gliders. An implementation of a Signal K central server for boats. Stonefish is an advanced C++ simulation library designed for marine robotics. HoloOcean enables easy simulation of marine robotics. OpenSSN is a submarine simulation. Aquabot is a self-Improving Autonomous Underwater Manipulation. ROV Simulator is a modular simulator. BlueROV2 ROS 2. OpenROV is a DIY telerobotics community. OpenProp is free software for the design and analysis of marine propellers and horizontal-axis turbine

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
